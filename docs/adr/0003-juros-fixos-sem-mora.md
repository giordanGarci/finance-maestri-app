# Juros fixos na criação, sem juros de mora automáticos (MVP)

Os Juros de um Empréstimo são calculados uma única vez, na criação, como uma taxa sobre o Principal, e não são recalculados automaticamente quando uma Parcela atrasa. É uma simplificação deliberada para o MVP: cobrar algo extra por atraso fica a critério manual do usuário, evitando lógica de acúmulo/composição não pedida e com efeitos financeiros sensíveis se implementada errado.
