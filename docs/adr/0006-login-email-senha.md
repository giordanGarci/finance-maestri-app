# Login por e-mail/senha em vez de Google Sign-In

O plano original assumia Firebase Auth com Google Sign-In usando só um `webClientId`, funcionando no Expo Go via proxy de autenticação do Expo. Investigação confirmou (documentação atual do Expo e do Google) que isso não é mais verdade: login Google nativo no Android exige uma biblioteca nativa (`@react-native-google-signin/google-signin` ou equivalente) com um client ID Android real validado por assinatura, o que não roda no Expo Go e exigiria development build só para autenticar. Como o objetivo real era proteger os dados contra acesso não autorizado ao celular, não especificamente reaproveitar a conta Google, trocamos para login por e-mail/senha do Firebase Auth: funciona normalmente no Expo Go, sem client ID de plataforma nem development build. Notificações locais continuam sendo a única funcionalidade que exige development build (ver ADR-0002 e o ticket 08).
